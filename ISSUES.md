## Priority 1 — Bugs / Correctness

### [BUG-01] `stats.ts` — no try/catch on any route ✅ FIXED
**File:** `server/src/routes/stats.ts` (all 5 routes: lines 9, 43, 79, 112, 138)
**Problem:** Every `await pool.query(...)` is bare. If the DB goes down, routes throw unhandled exceptions and Express returns an HTML 500 page instead of JSON.
**Fix:** Wrap each route handler body in `try { ... } catch (err) { res.status(500).json({ error: serverError(err) }); }`.
- [x] `/stats/summary`
- [x] `/stats/currently-playing`
- [x] `/stats/recently-added`
- [x] `/stats/completions-by-month`
- [x] `/stats/genre-breakdown`

### [BUG-02] DB — missing `user_id` index on `vault_entries` ✅ FIXED
**File:** `server/src/db/schema.sql`
**Problem:** Every vault/stats/discover query filters on `user_id`, but there is no index on that column. All per-user queries do a full table scan.
**Fix:** Added `idx_vault_entries_user_id` and `idx_vault_entries_user_status` to `schema.sql`.
Apply to production DB via `migrate_001_vault_indexes.sql`.
- [x] Add index migration

### [BUG-03] DB — no `UNIQUE(game_id, user_id)` constraint on `vault_entries` ✅ FIXED
**File:** `server/src/db/schema.sql`
**Problem:** Duplicate-prevention logic in `POST /api/games` is application-level only. A race condition (two parallel requests to add the same game) can insert duplicate rows.
**Fix:** Added `uq_vault_game_user` unique index to `schema.sql`.
Apply to production DB via `migrate_001_vault_indexes.sql`.
- [x] Add constraint migration

### [BUG-04] Auth — changing password does not invalidate the old JWT ✅ FIXED
**File:** `server/src/routes/auth.ts` (`PATCH /auth/password`, line 124)
**Problem:** After a password change, the old JWT remains valid for up to 7 days.
**Fix:** `PATCH /auth/password` now RETURNs the user row after update, signs a fresh JWT, and sets a new cookie before responding.

## Priority 3 — Data Quality / UX

### [DATA-01] `getStalledGames` — no minimum idle threshold ✅ FIXED
**File:** `server/src/services/discovery/rule-based.ts` (line 56)
**Problem:** Any game with `status = 'playing'` appears in "Left on the shelf," including one updated an hour ago. The section title implies genuine staleness.

AND EXTRACT(DAY FROM NOW() - ve.updated_at) >= 7

## Design System Notes (non-blocking)

Use `var(--destructive)` or `var(--vp-warn)` instead of the Tailwind red literal.

Minor cosmetic concern. Replacing hex pairs with `--vp-*` token references would improve theme cohesion but requires verifying SVG `stopColor` CSS variable support.

## Auth Design Notes (accepted trade-offs, no immediate action)

- **`isAdmin` from JWT, not DB:** If admin demotion is ever added, tokens issued before the demotion remain valid until expiry. Acceptable for a personal app; would need a token blacklist or short expiry to fix properly.
- **CSRF risk from `sameSite: 'none'`:** Required for the Vercel→Railway cross-origin setup. Mitigations: CSRF token header, or validating `Origin` on mutating routes. Low risk for personal use.
