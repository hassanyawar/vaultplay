## Project intent

VAULTPLAY is a personal, non-commercial web application developed for the purpose of tracking video games played, in progress, and pending. This project is undertaken as a self-directed learning exercise, with the intent to build practical experience in full-stack web development while leveraging AI-assisted tooling responsibly. The project is scoped to a single developer and is not intended for public distribution, monetization, or commercial deployment in its initial phase.

---

## Commitments & standards

### Code quality
TypeScript enforced throughout. ESLint and Prettier configured from M1. No code merged without passing lint.

### Data integrity
All game data stored in structured PostgreSQL schema. No unvalidated writes to the database.

### Privacy
No personal data shared with third-party services beyond RAWG API game metadata. No analytics or tracking.

### Security
Environment variables used for all secrets. AI-assisted security audit conducted before M6 deployment.

### AI use transparency
AI assistance used for scaffolding, code generation, and feature logic. All AI output reviewed and understood before use.

### Version control
All work tracked via Git. Milestone boundaries marked with tags. No force-pushes to main branch.

---

## Milestone accountability

Each milestone carries a defined exit criterion that must be met before progression. The author commits to honest self-assessment at each gate — partial completion is documented, not masked. A milestone is considered done only when its exit criterion is demonstrably satisfied in a working local or deployed environment.

---

## Third-party dependencies

This project makes use of the RAWG Video Games Database API under its free-tier terms, and the Anthropic Claude API for AI-powered features. Use of both APIs is subject to their respective terms of service. The author commits to staying within free-tier usage limits during development and to reviewing API terms before any public deployment.

## Review & amendment

This statement reflects the project's intent at the time of writing (May 2026). It may be amended as the project evolves. Any material change in scope, deployment target, or commercialization intent will require a revised statement before proceeding.
